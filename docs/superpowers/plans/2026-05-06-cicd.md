# CI/CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Set up automated linting and CPU testing via GitHub Actions, local pre-commit hooks, and manual HPC GPU test scripts.

**Architecture:** One GitHub Actions workflow runs black, flake8, and CPU-only pytest on every push and PR. A pre-commit config enforces formatting locally before each commit. Two shell scripts handle manual GPU testing on HPC nodes with CUDA 12.4 and 13.0. pytest markers separate GPU tests from CPU tests throughout.

**Tech Stack:** Python 3.12, uv, pytest, black, flake8, pytest-cov, GitHub Actions (ubuntu-latest), pre-commit

## Task 4: Create GitHub Actions workflow

**Files:**
- Create: `.github/workflows/lint-cpu.yml`

- [ ] **Step 1: Create the .github/workflows directory**

```bash
mkdir -p .github/workflows
```

- [ ] **Step 2: Create .github/workflows/lint-cpu.yml**

```yaml
name: Lint and CPU Tests

on:
  push:
    branches: ["**"]
  pull_request:
    branches: [main]

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: astral-sh/setup-uv@v4
        with:
          enable-cache: true

      - name: Install dependencies
        run: uv sync --extra cpu --extra dev

      - name: Check formatting
        run: uv run black --check . --line-length 88

      - name: Lint
        run: uv run flake8 x_fuse/ tests/

  test:
    runs-on: ubuntu-latest
    needs: lint
    steps:
      - uses: actions/checkout@v4

      - uses: astral-sh/setup-uv@v4
        with:
          enable-cache: true

      - name: Install dependencies
        run: uv sync --extra cpu --extra dev

      - name: Run CPU tests
        run: uv run pytest -m "not gpu" --cov=x_fuse --cov-report=xml -v
```

- [ ] **Step 3: Validate the YAML syntax locally**

```bash
uv run python -c "import yaml; yaml.safe_load(open('.github/workflows/lint-cpu.yml'))" && echo "YAML valid"
```

Expected: `YAML valid`

- [ ] **Step 4: Commit and push to trigger the workflow**

```bash
git add .github/workflows/lint-cpu.yml
git commit -m "Add GitHub Actions workflow for lint and CPU tests"
git push
```

- [ ] **Step 5: Verify workflow runs on GitHub**

Go to your repository on GitHub → **Actions** tab. You should see the `Lint and CPU Tests` workflow running. Wait for it to complete.

Expected: both `lint` and `test` jobs show green checkmarks. If either fails, read the job log — the error will indicate which command failed and why.

## Usage Reference

### Day-to-day (automatic)
- `git commit` → pre-commit runs black and flake8 automatically
- `git push` → GitHub Actions runs lint and CPU tests automatically

### Before merging to main (manual)
SSH into an HPC interactive GPU job, navigate to the repo, then:

```bash
# For CUDA 12.4 nodes:
bash scripts/hpc_gpu_test_cu124.sh

# For CUDA 13.0 nodes (newer GPUs, longer queue):
bash scripts/hpc_gpu_test_cu130.sh
```

### Writing new GPU tests
Decorate with `@pytest.mark.gpu`:

```python
@pytest.mark.gpu
def test_my_gpu_behaviour():
    t = torch.tensor([1.0]).cuda()
    assert t.device.type == "cuda"
```

CPU CI skips these automatically. HPC scripts run only these.
